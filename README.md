# Wayward!

*Wayward!* is a rules-light sword-and-sorcery tabletop roleplaying game about plundering dark labyrinths. It is based on *Barbaric! Second Edition* and includes adapted and original rules by George Zackrison.

If you are looking for the rules, click here:
[Core Rules](/Core-Rules.html)

If you need a character sheet, click here:
[Character Sheet](/assets/Wayward-Character-Sheet-Playtest.pdf)

## Technical Information

The repository contains:

- `Core-Rules.html` — the canonical core rules.
- `Draft.md` — provisional and playtest material.
- `styles.css` — shared presentation for the HTML documents.
